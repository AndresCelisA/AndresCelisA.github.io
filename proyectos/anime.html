Catálogo Anime

Aplicación web para consultar y explorar animes de temporada, desarrollada como proyecto personal.

Sobre el proyecto

Proyecto personal actualmente en desarrollo, enfocado en crear una aplicación web para consultar y explorar los animes disponibles durante cada temporada.

El proyecto busca aplicar tecnologías modernas de desarrollo web y mejorar progresivamente la experiencia de navegación y consulta de información.

Objetivos

  • Crear un catálogo organizado de animes de temporada.
  • Facilitar la exploración y búsqueda de contenido.
  • Desarrollar una interfaz moderna y responsive.
  • Aplicar React en un proyecto real de desarrollo personal.
  • Integrar progresivamente nuevas funcionalidades.

Estado actual

El proyecto se encuentra actualmente en desarrollo. La arquitectura y funcionalidades se irán ampliando progresivamente durante su desarrollo.
