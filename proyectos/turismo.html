UNIVERSITARIO · DESARROLLO WEB

Página web de turismo

Desarrollo de una página web orientada a la promoción turística de una ciudad.

Sobre el proyecto

Proyecto universitario orientado al desarrollo de una página web turística para presentar información y atractivos de una ciudad.

Mi participación

Desarrollo del proyecto web, incluyendo la estructura, interfaz y funcionalidades necesarias para presentar la información turística.

  • Diseño y estructura de la página web.
  • Desarrollo de la interfaz.
  • Implementación de funcionalidades utilizando PHP.
  • Diseño responsive mediante Bootstrap.
  • Pruebas y corrección de errores.

Resultado

Página web funcional para presentar información turística de la ciudad de forma organizada y accesible.
