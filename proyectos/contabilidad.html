PRÁCTICA UNIVERSITARIA · DESARROLLO WEB

Funcionalidad de Contabilidad

Desarrollo de una funcionalidad web orientada a la gestión de información contable para una entidad pública.

Sobre el proyecto

Proyecto desarrollado durante una práctica universitaria, enfocado en la implementación de una funcionalidad de contabilidad dentro de una plataforma web existente.

Mi participación

Participé en el desarrollo de la funcionalidad, trabajando en la interfaz web, lógica de aplicación y manejo de información mediante una base de datos.

  • Desarrollo de la interfaz web.
  • Implementación de funcionalidades en PHP.
  • Integración con base de datos SQL.
  • Gestión y procesamiento de información contable.
  • Uso de Bootstrap para la interfaz.
  • Pruebas y corrección de errores.

Resultado

Se desarrolló e integró la funcionalidad solicitada, permitiendo gestionar la información correspondiente al módulo de contabilidad.
