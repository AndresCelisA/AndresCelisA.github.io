PERSONAL · APLICACIÓN MÓVIL

Aplicación Android

Aplicación móvil para organizar y administrar una lista de tareas pendientes.

Sobre el proyecto

Proyecto personal orientado al desarrollo de una aplicación móvil para administrar una lista de tareas y actividades pendientes.

Características

  • Creación de tareas pendientes.
  • Visualización de tareas.
  • Gestión de actividades.
  • Interfaz adaptada a dispositivos móviles.

Objetivo

Aplicar conocimientos de desarrollo móvil mediante la creación de una aplicación sencilla y funcional para la gestión de tareas.
